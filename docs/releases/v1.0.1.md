DiskScope 1.0.1: cleanup hardening and a scanner fix for 4K-native disks.

Download **DiskScope-1.0.1-win-x64.zip**, extract it over your previous folder, and restart your MCP client.

- **Cleanup path pinning:** ancestor directories are now opened with access that makes their no-delete sharing effective, so they cannot be renamed or swapped for a junction mid-operation. Preview and deletion also verify each file handle's final path and re-apply protected-path rules to it.
- **Read-only files:** deletion uses `FileDispositionInfoEx` with POSIX semantics and ignore-read-only, so caches such as `.git/objects` no longer stop execution at the first read-only file. Older systems fall back to the legacy call.
- **4K-native disks:** MFT update-sequence repair now uses NTFS's fixed 512-byte stride instead of the volume sector size, which previously made scans fail on 4Kn volumes.
- **Stricter tests:** refusal checks assert the expected exception and reason; new regressions cover synthetic 1 KiB/4 KiB MFT records, prefixed protected paths, ancestor locking, handle-path comparison, and read-only deletion.

Validated with 55 core checks and 24 packaged MCP/CLI checks, plus a live NTFS scan with zero parse failures. Not yet verified on physical 4Kn hardware.

**Cleanup still permanently deletes files and bypasses the Recycle Bin.** The executable remains unsigned; verify it with the SHA-256 checksum.
