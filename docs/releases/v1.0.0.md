DiskScope's first public release: progressive NTFS disk analysis and guarded cleanup for AI agents.

Download **DiskScope-1.0.0-win-x64.zip**, extract it, and run `DiskScope.exe help` or `Register-Codex.ps1`. No separate runtime installation is needed.

- JSON CLI and standard local stdio MCP, with 12 tools.
- One-level directory disclosure, physical allocation sorting, largest-file queries, and hard-link accounting.
- Background scan, cleanup preview, and execution jobs with progress queries.
- One-volume index cache with 120-second idle release and explicit `disk_release`.
- Optional analysis-only mode; exact-file cleanup previews, identity validation, reparse refusal, and durable audit logs.
- English / 简体中文 documentation, MIT source, and SHA-256 checksums.

Validated with 39 core checks and 24 packaged MCP/CLI checks. GitHub Actions builds and tests the release artifacts before publication.

**Requirements:** Windows x64, local NTFS. Full-volume scanning needs administrator rights. The release was verified locally on Windows 11.

**Cleanup permanently deletes files and bypasses the Recycle Bin.** Execute only reviewed, authorized scopes and poll jobs through completion. The executable is currently unsigned. Read the safety and integration documentation included in the ZIP.
